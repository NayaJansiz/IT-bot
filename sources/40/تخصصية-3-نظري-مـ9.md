Visual Components
<!-- p2 -->
What are Visual Components?
●
They are the various UI elements that can be
used to display information and perform
interaction with the user
●
Knowing which elements to use in different
sitation is half the battle in building a good
UI/UX
<!-- p3 -->
Types of VCs
●
We can classify UI elements in 3 categories:
–
Visual View: they do one thing only provide the user
with information
–
Action: they are responsible of performing some
type of action
–
Input: provide an input to the system

other choice

maintain consistant look along the application
