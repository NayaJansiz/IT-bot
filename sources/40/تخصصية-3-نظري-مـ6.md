What Is Human Interface Guidelines
●
Why so important ?
– The central aim of a HIG is to create a
consistent experience across the
environment
– This means both applying the same
visual design and creating consistent
access to and behavior of common
elements of the interface

Google Material Design
– Color system
●
Ensures consistent semantics
●
Makes design scalable across platforms
●
Helps designers avoid arbitrary color assignments

Example of HIG
● Google Material Design
– Motion System
● Easing & Timing in M3
● Easing Curves
– Material 3 uses updated, physics-inspired easing curves:
● Standard:
● Standard (default) → smooth, natural transition
● Accelerate and Decelerate → for enter/exit transitions
● Emphasized:
● Emphasized → more expressive, dynamic
● Emphasized Decelerate → prominent entrances
● Emphasized Accelerate → prominent exits
– Timing Values
● Standard duration: 200–400 ms
● Quick actions: 100–150 ms
● Large transitions: 300–450 ms
● Emphasized motion uses longer durations to feel "playful"

● Cross-screen motion that transforms a component into a

● Useful for content that changes within the same layout
