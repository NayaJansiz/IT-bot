Flat Design
●
Flat design is all about
minimalism, the smallest
amount of interface to do
the job, including the least
amount of visual effects,
icons, buttons, possible
actions, menus, the least
amount of everything. Also,
There was no need for
beveled edges, gradients,
reflections, and
skeuomorphism. The digital
interface should be
exploited for its own
strengths.

●

expects the car to start, but sometimes this
is not the case and the engines hums for a

Why Visual Effects
●
Color Change
–
Another use of color change, is to indicate
the changing of the state of the element, for
example the color of a button might change
to a lighter tone when the mouse hovers on
it indicating this element in the current data
context of application can be interacted
with, while changes to dark tone when
clicking on it to indicate an action has been
issued, returning to its normal color when
we release the mouse button.
<!-- p10 -->
Why Visual Effects
●
Cursor Change
–
An oldy but goody, this visual effects changes the
shape of the mouse cursor based on the
element or the state of the application, for
example the normal mouse cursor is a pointer,
but when the mouse placed on an editable
element, like a text box, it changes into a text
caret (capital letter I), or to hand when it is
hovering on top of link. In case the application is
processing something, it changes into an hour
glass or a spinner.
–
these effect provides a feedback for the user
about the interactivity of the elements and the
state of the application.

Why Visual Effects
●
Spinners
– A spinner is simple interface element with one object,
show that the application is processing things without
knowing when the work is done or how much of remains .
In traditional desktop application, a simple long loop could
freeze the application, this makes the application appear as
if frozen, while in fact it is working, to solve this a simple 2
step solution is used, first implement the loop on a
separate thread from the UI thread, second implement
some visual element showing the application is processing
like a spinner, or a progress bar.
– However a modern version has appeared with unique
appearance, a group of geometric shapes with different
colors behind a frosty glass moving around to indicate the
application is working on something

Why Visual Effects
●
Progress Bar
–
A progress bar simply, is a rectangle getting filled
with another rectangle.
–
This element is used convey how much of the
work has been finished.
–
In the old days, a small text indicating the
percentage of the work done was placed in the
center of the bar.
–
Another version is similar to spinners is
indeterminate progress bar of which a small
rectangle keeps rocking back and forth in the big
rectangle used in the same way as a spinner.
