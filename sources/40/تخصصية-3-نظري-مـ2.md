1 - Colors
1 - 1 - What is Color
Physically, the color is composed of several light waves of different lengths, and the surface of an object
absorbs some and reflect the others, thus the color reflected is the seen by our eyes, camera sensors and
is considered the color of the object.
We can decompose the white lite into its elements (the rainbow) using a prism just as in Figure 1.
The importance of this cannot be understated, as it provides us with method we can use to create
and compose colors in the real world.
Transparent Material:
It is a material that allows the entire white light and all its component to pass through like normal
glass. However, there are translucent materials, material that are semi-transparent, in which all but few
of light colors are through.
For example, using green glass, all the colors are allowed to pass through except for green color which
is reflected.
1 - 2 - Color Wheel
This concept is important as it allows us to view the color as a single value like in HSB, HSV color
system not 3 components like in RGB color system.
It’s an abstract illustrative organization of color hues around a circle, which shows the relationships
between primary, secondary, tertiary colors ... etc.
Most color wheels are based on three primary colors, three secondaries, and the six intermediates
formed by mixing a primary with secondary, known as tertiary colors, for a total of 12 main divisions.
Some add more intermediates, for 24 named colors. They make use of the trichromatic model of color
like in Figure 2.

1 - 3 - Color Selection Methods
From the method of building the color wheel, we can deduce the method of which we can use to select
colors. However, we need to take into consideration not just the color (in the case of the color wheel
we call it the hue), but also the saturation (how much color in the color) and brightness (how light or
whiteness is in the color).
This is based on the HSV color system, in which the Hue determines the wavelength of the color (the
color value), Saturation determines how much color is in the color and Value determines the brightness
of it, in this system we can imagine the colors as points on the surface/inside of a cylinder, where the hue
represents the point on the central horizontal circle of the cylinder, the saturation is length of edge from
the center of the cylinder to the point on central circle, could be less than the radius of the ball, hence
we get less saturated colors, and the value/brightness is represented as the angle between that edge and
the vertical axis of the cylinder, where reaching the top means full color value (if the saturation is zero
we get white) and the bottom is black like in Figure 4.
• Complimentary: like in Figure 5(a) we select the colors based the diagonally opposite hue value,
while maintaining the same saturation and value, this is mostly suitable for 2 color based palettes
where we need a background and a foreground. Like red and green, orange and blue, When placed
adjacent to each other in a painting, complements make each other appear brighter. When mixed,
they have the opposite effect, neutralizing (or graying) each other.
• Triadic Color Scheme: like in Figure 5(b), this scheme consists of three colors that form an
equilateral triangle on the color wheel like the 3 primary colors, or 3 secondary color.
• Tetradic Color Schemes: like in Figure 5(c) ,Four colors that form a square or a rectangle on the
color wheel create a tetradic color scheme. This color scheme includes two pairs of complementary
colors, such as orange and blue and yellow-orange and blue-violet. This is also known as a “double-
complementary” color scheme.
• Analogous Color Schemes: like in Figure 5(d), analogous colors are adjacent (or close) to each
other on the color wheel. Analogous color schemes are good for creating unity because the colors
are already related. You can do a tight analogous scheme (a very small range of colors) or a loose
analogous scheme (a larger range of related colors). Used in charts as it can be very good to
represents difference in values.

1 - 4 - HSV Color Space
The HSV color space is probably the most powerful weapon on the arsenal of selecting colors, as it
contains 3 components:
• Hue: the wave length of a color represent as an angle on the color wheel, this value alone represents
the color we have unlike RGB which requires 3 values to represent a color, as a result we can separate
the color from other components of light and process it alone.
• Saturation: represents how much color is in the color, this value allows us to control the amount
of color we need from a certain wave length without changing it. colors with high saturation seems
more vibrant, while low value saturation makes the color appear washed out, like it has been in
the sun for far too long.
• Value: represents the amount of light shining on the color, in other words separates the light
component from the color component. at minimum value we get black, just black, while at the
highest value we get the color at full brightness, not white. Another way of looking at it is allowing
us to control the amount of black in the color
By utilizing these 3 values we can create a color pallette for the application based on one color like in
Figure 6, we see except for background, all colors have the same hue, but with variations in saturation
and value.

1 - 5 - Color Psychology
This concept is based on the idea that certain colors invokes specific emotions. This is very important
in advertisement, but less important in UI design, but can still provide help in selecting a brand color
in the application, it is NOT mandatory, but completely optional.
Some Colors invoke the following emotions:
1. Red: usually used for error and urgent attention, is associated with the heat of energy, passion and
love. We “see red” when we’re angry and it’s also the color of blood, power and danger, making it
a powerful color in branding.
2. Orange: As a secondary color, it combines the warmth and heat of red with the playfulness and
joy of yellow. It attracts attention without being as daring as red, and is used for warning signs
like traffic cones and high-visibility clothing. It’s an energetic color that can bring to mind health
and vitality, given its obvious link to oranges and vitamin C. It’s a youthful color as well, bringing
an element of vibrancy and fun.
3. Yellow: usually used for attention or warnings, Yellow is the color of the sun, smiley faces and
sunflowers. It’s a happy, youthful color, full of hope and positivity. It’s another color that grabs
your attention and for that reason can also be used to signify caution, like red and orange. Despite
being a positive color, yellow can also express fear.
4. Green: usually used for success or continuation. Green is universally associated with nature,
linked as it is to grass, plants and trees and is used heavily to describe healthy products . It
also represents growth and renewal, being the color of spring and rebirth. Another association
is “getting the green light” to go ahead, giving it an association with taking action. In the US,
green (and especially dark green) is also associated with money and so represents prosperity and
stability.
5. Blue: usually represents freedom, as it is the color of the sky and ocean. Blue is a serene and
calming color that represents intelligence and responsibility. Blue is cool and relaxing. Light baby
blue is peaceful, while dark blue can signify depth and power. It is the most popular color in the
world, both when it comes to personal preferences (for both genders) and usage in business logos.
It’s the go-to color for trusted, corporate institutions, often in combination with a mature gray.
Also light blue is used for branding baby items for boys
6. Purple: it is an interesting color, it’s both warm and cool and combines the passion and energy of
red with the calm and serenity of blue. Because of its associations with royalty, purple is inherently
prestigious and luxurious. Purple dye was historically expensive, which meant that only wealthy
rulers could afford it. The ruling classes and kings and queens of old would wear purple and Queen
Elizabeth I even forbade anyone outside the royal family from wearing it. Purple is also associated
with religion and spirituality, since the ancient rulers were thought of as descendants of the gods
and the color holds a special meaning in religions including Catholicism, Judaism and Buddhism.
7. Pink: In modern times, it’s impossible to see pink and not think of little girls, cotton candy and
brightly colored bubble gum. Pink represents femininity and romance, sensitivity and tenderness.
It’s inherently sweet, cute and charming.
8. Brown: is a natural color, associated with the earth and as a result giving a sense of stability and
support. Given its link to the earth and nature, brown brings to mind farming and agriculture and
other outdoorsy activities. It’s warm and friendly, practical and dependable, and can also represent
the old-fashioned and well established.
<!-- p10 -->
9. Black: is an incredibly versatile color and probably the most used color in graphic design. When
it comes to branding and marketing, black is generally associated with exclusivity, power and
elegance. It’s bold, powerful and a little mysterious, which makes it a firm favorite of modern
brands. Depending on the design context, it can be used to create a cool and unapproachable look
as well. At the same time, it’s an inherently neutral color that works well in combination with any
other color and is often used for typography and other central, grounding design elements.
10. White: it’s the absence of any color. In Western cultures it’s often associated with virginity (think
of brides wearing white on their wedding day as a symbol of purity), while in some East Asian
countries it’s the color of mourning. When used in design and branding, white creates a minimalist
aesthetic. It can be very simple, clean and modern. It’s also the most neutral color of all and can
be quite non-descript as a base for other, more exciting, colors.
1 - 6 - Color Palettes
1 - 6 - 1 - What is Color Palette?
A color palette is a combination of colors used by UI designers when designing an interface. When used
correctly, color palettes form the visual foundation of your brand, help to maintain consistency, and
make your user interface aesthetically pleasing and enjoyable to use.
You can use a color palette to define the colors required for your UI design and follow these color
during the design phase to create a color-cohesive application.
1 - 6 - 2 - WCAG
The Web Content Accessibility Guideline is a set of guidelines set by W3 Consortium to help designers
and developers creating web pages usable by people with disability be it visual, auditory or physical.
What we need of this standard is the contrast ratio measurement calculating the contrast value
between two colors. This is based on 3 levels A, AA, and AAA, we need to focus on AA and AAA.
1. Level AA: The visual presentation of text and images of text has a contrast ratio of at least 4.5:1,
except for the following:
• Large Text: Large-scale text and images of large-scale text have a contrast ratio of at least
3:1
• Incidental: Text or images of text that are part of an inactive user interface component, that
are pure decoration, that are not visible to anyone, or that are part of a picture that contains
significant other visual content, have no contrast requirement.
• Logotypes: Text that is part of a logo or brand name has no contrast requirement.
2. Level AAA: The visual presentation of text and images of text has a contrast ratio of at least
7:1, except for the following:
• Large Text: Large-scale text and images of large-scale text have a contrast ratio of at least
4.5:1;
• Incidental: Text or images of text that are part of an inactive user interface component, that
are pure decoration, that are not visible to anyone, or that are part of a picture that contains
significant other visual content, have no contrast requirement.
• Logotypes Text that is part of a logo or brand name has no contrast requirement.
There are several contrast calculators with the ability to show contrast ratio and its compliance with
WCAG standards.

1 - 6 - 5 - Building Your Own Palette
Preferably, use an already built tool that can generate a palette based on one or few base colors, I
personally like to use coolors.co, it is simple, easy to use and surprisingly efficient.
But if you want to do it manually, here are few things to consider:

methods along with others, to create a set colors that not only contrasts the base color, but also
each other.
4. No Eyesore: make sure the selected colors are not an eyesore, sometimes they do contrast each
other, but no in a good way.
1 - 7 - Color Temperature
Color temperature is a parameter describing the color of a visible light source by comparing it to the
color of light emitted by an idealized opaque, non-reflective body. The temperature of an ideal emitter
that matches the color most closely is defined as the color temperature of the original visible light source.
It is usually measured in kelvins.
It is a way to describe the light appearance provided by a light bulb. It is measured in degrees of
Kelvin (K) on a scale from 1,000 to 10,000. Typically, Kelvin temperatures for commercial and residential
lighting applications fall somewhere on a scale from 2000K to 6500K.

1 - 9 - Color Blindness
These are people who cannot see the normal color spectrum the average human sees, and there are
several types of color blindness:
• Red-Green:
– Protanopia: can’t see red
– Protanomaly: can see some shades of red
– Deuteranopia: can’t see green
– Deuteranomaly: can see some shades of green
• Blue-Yellow:
– Tritanopia: can’t see blue
– Tritanomaly: can see some shades of blue
• Monochromacy: Zero color vision only shades of gray
Developing the interface to provide a good experience to all these type is kind of an expensive undertake.
Therefore, the best approach is to actually create a high contrast color ratio, while color-blind people
can’t see a color, they can see its lightness. JetBrains IDEs provide an option to enable color schemes
for 2 types of color blindness Protanopia, Deuteranopia

2 - 2 - Fixed vs Variable Width
Some fonts have a fixed width, meaning all the letters supported by the font have the same width
regardless of the shape of letter, number or symbol provided being in the same font size, while other
fonts a variable width, see Figure 14.
In many cases, we use fixed width fonts in code editors and terminal applications, and example of
this line is Source Code Pro, JetBrains Mono and many others.
This type of fonts (Monospaced/Fixed Width) can be useful in UI design as you have the ability to
predict the width of the word by defining the number of letters in word or sentence, which allows us to
define the width of objects like textboxes , buttons and fill it in with placeholder text for prototyping.
However, variable width fonts are more natural to the eye because naturally letters are not of the
same width, and for this is reason it is used in UI, while traditionally fixed width is used for code editors
and terminals.

3 - Iconography
3 - 1 - Why use Icons?
It is very simple, a picture worth a thousand word, in other words, you can use icons to convey a verity
of actions and status with the need for words, like the save icon, which looks like an old school floppy
disk used to save backup data, or an open folder icon for opening files and folders in applications.
Other samples include, the arrows used by media players to indicate play, forward, backward and the
square to stop, and two vertical bars for pause.
This is common knowledge these days, which no longer needs to be redefined. using it in your UI
conveys a sense of similarity and familiarity making it easier to use by the end user because they are
accustomed to these common icons which in turn reduces the time needed to learn the interface.
Other well known icon are for example what is used in word processors to indicate text alignment
(left, middle and right), or the bold, italic and underline styles.
Other icons a simply used with other icons to indicate actions, for example the plus sign (+), the
minus (-), or a simple pen by adding these icons to other icons to indicate add, delete and edit icons for
a certain object.

3 - 3 - SVG
Scalable Vector Graphics (SVG) is a famous and wildly used XML-based vector image format for two-
dimensional graphics with support for interactivity and animation. The SVG specification is an open
standard developed by the World Wide Web Consortium (W3C) since 1999.
Defined in a vector graphics format, SVG images can be scaled in size without loss of quality. SVG
images and their behaviors are defined in XML text files, which means that they can be searched, indexed,
scripted, and compressed. As XML files, SVG images can be created and edited with any text editor, as
well as with drawing software.

3 - 4 - Icon Fonts
3 - 4 - 1 - What is Icon Fonts?
Imagine a world where you can treat icons like letters, you can make them as big as you want but without
losing quality or getting distorted edges and borders, and you can change the color super easily.
What if I told that such a world exists? In real words, letters in fonts are nothing but a vector graphic
images, so some people got together and got the idea, what if instead of putting letter graphics in the
font, we put commonly used icons? And thus the font icon was born.
An early version is the infamous Wingdings in Microsoft Windows, which provided weird icons instead
of normal letters, modern font icons includes the most famous Font Awesome, Simple Line, Linear Icons,
Ionicons and many others.
The beauty of this is the ability to treat icons like letters including changing the color easily and
changing the size without the lose of quality. However, the downside is the a icons will only be
monochromatic, you can have several icons each with its own color, but within a single icon there
can only be one color, while svg, png and other image based formats can have multiple colors with in a
single icon.
This is not a bad thing, depending on your UI specifications and requirements you can use one or
the other or a combination of both
