Query Optimization Strategies
 Query Optimization Strategies
o Heuristics-based optimization
o Applies heuristic rules to modify the internal representation of a query in order to get the optimized
query representation
o Cost-based optimization
o Uses traditional optimization techniques that search the solution space to a problem for a solution
that minimizes an objective (cost) function
