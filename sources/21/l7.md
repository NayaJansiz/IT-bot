Dictionary-based Coding
 LZW uses fixed-length codewords to represent
variable-length strings of symbols/characters that
commonly occur together.
 the LZW encoder and decoder build up the same
dictionary dynamically while receiving the data.
 LZW places longer and longer repeated entries into
a dictionary, and then emits the
code for an
element, rather than the string itself, if the element
has already been placed in the dictionary.

Arithmetic Coding
 Arithmetic coding is a more modern coding method that usually
out-performs Huffman coding.
 Huffman coding assigns each symbol a codeword which has an
integral bit length. Arithmetic coding can treat the whole message
as one unit.
 A message is represented by a half-open interval [
a; b) where
a
and
b are real numbers between 0 and 1. Initially, the interval is
[0
; 1). When the message becomes longer, the length of the
interval shortens and the number of bits needed to represent the
interval increases.
