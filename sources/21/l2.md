Printer DPI
- DPI means Dots Per Inch. This is what your printer will recognize
when it prints your image.
- Your computer monitor is configured to view items at PPI, or Pixels
Per Inch. This can cause a great disparity when trying to get what
looks like a great image on your screen to come out looking just as
good on your printer

1-bit Images
Each pixel is stored as a single bit (0 or 1), so also referred to as
binary image.
Such an image is also called a 1-bit monochrome image since it
contains no color (e.g. ‘Lena’).

Image File Formats
• Raster formats (JPEG, PNG, GIF, BMP, TIFF) are pixel-based and resolution-
dependent
• Vector formats (SVG, EPS) are scalable and ideal for graphics that need resizing
• Document container formats (PDF, PS) can embed both raster and vector images,
along with text and layout instructions
Choosing the right format depends on:
• Image type (photo vs. graphic)
• Need for transparency or animation
• File size constraints
• Whether the image is part of a printable or shareable document
• Compatibility with publishing or printing workflow
