debugger >>linker settings click "Add button" in link libraries
part and browse and select the "libbgi.a" file.
4. In right part (i.e. other linker options) paste the next commands:
-lbgi -lgdi32 -lcomdlg32 -luuid -loleaut32 -lole32
5. Click OK.

Using the WinBGIm Graphics Library in Code::Blocks:
You can now compile and run programs that use the WinBGIm
graphics library, such as this one that opens a small window, draws
a circle and waits for the user to press a key:
#include <graphics.h>
int main( )
{
initwindow(400, 300, "First Sample");
circle(100, 50, 40);
while (!kbhit( ))
{
delay(200);
}
return 0;
}
